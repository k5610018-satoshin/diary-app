# ふりかえり日記 GAS版 セットアップ手順

## 概要

Google Apps Script（GAS）で動作する「ふりかえり日記」アプリです。
Google スプレッドシートをデータベースとして使用し、児童の振り返り入力と教師のコメント機能を提供します。

### 主な機能

| 機能 | 説明 |
|------|------|
| 振り返り入力 | テキスト入力 + 音声入力（OpenAI Whisper API） |
| AIフィードバック | GPT APIによる自動フィードバック・質問生成 |
| 音声入力 | マイクで話した内容をAIが文字起こし |
| 追記機能 | AIの質問に答えて深い振り返りを促進 |
| 先生コメント | 教師が児童の振り返りにコメントを追加 |
| カレンダー表示 | 月別の振り返り一覧をカレンダーで表示 |
| ダッシュボード | 教師用の統計情報・未コメント一覧 |
| CSV出力 | 全データのCSVエクスポート |

## セットアップ手順

### Step 1: Google スプレッドシートを作成

1. [Google Sheets](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成
3. 名前を「ふりかえり日記」などに変更

### Step 2: Apps Script を開く

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を選択
2. Apps Script エディタが開く

### Step 3: ファイルを作成

Apps Script エディタで以下のファイルを作成します。
**「＋」ボタン** からファイルを追加してください。

#### GS ファイル（サーバーサイド）

| ファイル名 | 説明 |
|-----------|------|
| `Code.gs` | メインコード（デフォルトで存在。中身を置き換え） |
| `Database.gs` | スプレッドシート操作 |
| `GPT.gs` | OpenAI API連携（音声認識・フィードバック） |

#### HTML ファイル

**「＋」→「HTML」** を選択して作成します。

| ファイル名 | 説明 |
|-----------|------|
| `StudentView.html` | 児童用画面 |
| `StudentJS.html` | 児童用JavaScript |
| `TeacherView.html` | 教師用管理画面 |
| `TeacherJS.html` | 教師用JavaScript |
| `Styles.html` | 共通CSSスタイル |

### Step 4: コードをコピー

`gas/` フォルダ内の各ファイルの内容を、対応する Apps Script ファイルにコピー＆ペーストしてください。

### Step 5: 初期セットアップ実行

1. Apps Script エディタで `Code.gs` を選択
2. 関数セレクタで `setupSpreadsheet` を選択
3. **「実行」** ボタンをクリック
4. 初回実行時は権限の承認が必要です（「詳細」→「安全でないページに移動」→ 許可）
5. スプレッドシートに4つのシートが自動作成されます:
   - 児童マスタ
   - 振り返り
   - 先生コメント
   - 設定

### Step 6: OpenAI API キーの設定

1. [OpenAI API](https://platform.openai.com/api-keys) でAPIキーを取得
2. スプレッドシートの「設定」シートを開く
3. `OPENAI_API_KEY` の行の「値」列にAPIキーを入力

> **注意:** APIキーには利用料金がかかります。GPT-4o-mini を推奨します（低コスト）。

### Step 7: Webアプリとしてデプロイ

1. Apps Script エディタで **「デプロイ」→「新しいデプロイ」** を選択
2. 設定:
   - **種類:** ウェブアプリ
   - **説明:** ふりかえり日記 v1
   - **次のユーザーとして実行:** 自分
   - **アクセスできるユーザー:** 全員
3. **「デプロイ」** をクリック
4. 表示される **Web アプリの URL** をコピー

### Step 8: アプリにアクセス

- **児童用:** `{デプロイURL}?page=student`（またはURLそのまま）
- **教師用:** `{デプロイURL}?page=teacher`

## 使い方

### 児童の使い方

1. 初回は「はじめて使う」タブから名前・パスワード・クラスを登録
2. ログイン後、右下の ✏️ ボタンで新しいふりかえりを作成
3. タイトル・カテゴリ・気分を選んで内容を入力
4. 🎤 マイクボタンで音声入力も可能
5. 保存するとAIからフィードバックと質問が届く
6. AIの質問に「こたえる」ボタンで追記できる
7. 先生からのコメントは振り返り詳細で確認

### 教師の使い方

1. 教師用URL（`?page=teacher`）にアクセス
2. パスワード（初期値: `teacher2024`）でログイン
3. **ダッシュボード:** 統計と未コメントの振り返り一覧
4. **振り返り一覧:** 全児童の振り返りを確認・コメント
5. **児童管理:** 登録児童の一覧と振り返り数
6. **設定:** APIキー・パスワード変更・CSV出力

## トラブルシューティング

### 「権限がありません」エラー
→ 再デプロイしてください。Apps Scriptエディタ → デプロイ → デプロイを管理 → 新しいバージョン

### AIフィードバックが生成されない
→ 設定シートの `OPENAI_API_KEY` を確認してください。教師画面の設定タブで接続テストもできます。

### 音声入力が動かない
→ ブラウザのマイク権限を許可してください。HTTPS環境が必要です（GASデプロイURLはHTTPS）。

### データが表示されない
→ スプレッドシートの初期セットアップ（`setupSpreadsheet`）を再実行してください。

### コードを変更した場合
→ 必ず新しいバージョンとしてデプロイし直してください（デプロイ → デプロイを管理 → 編集 → バージョン: 新しいバージョン）。

## 料金について

- **Google Apps Script / スプレッドシート:** 無料
- **OpenAI API:**
  - GPT-4o-mini: ~$0.15/100万トークン（1回の振り返りフィードバック: 約$0.001未満）
  - Whisper: ~$0.006/分（音声認識）
  - クラス30人が毎日使っても月額数百円程度
